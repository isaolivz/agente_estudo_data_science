CIENCIA DE DADOS - GUIA COMPLETO PARA INICIANTES

1. O QUE E CIENCIA DE DADOS?

Ciencia de Dados e um campo interdisciplinar que combina estatistica, matematica, programacao e conhecimento de dominio para extrair insights e conhecimento de dados. O objetivo e transformar dados brutos em informacoes uteis para tomada de decisao.

A area surgiu da necessidade de analisar grandes volumes de dados (Big Data) gerados por empresas, redes sociais, sensores e dispositivos IoT.

2. PILARES DA CIENCIA DE DADOS

A Ciencia de Dados se apoia em tres pilares fundamentais:

2.1. ESTATISTICA E MATEMATICA
- Probabilidade: base para entender incertezas
- Estatistica descritiva: media, mediana, desvio padrao
- Estatistica inferencial: testes de hipotese, intervalos de confianca
- Algebra linear: matrizes, vetores, autovalores
- Calculo: otimizacao, gradientes

2.2. PROGRAMACAO E TECNOLOGIA
- Python: principal linguagem da area
- Bibliotecas: Pandas, NumPy, Scikit-learn, Matplotlib
- SQL: para consultar bancos de dados
- R: alternativa para analise estatistica
- Big Data: Hadoop, Spark, Cloud Computing

2.3. CONHECIMENTO DE NEGOCIO (DOMINIO)
- Entender o problema de negocio
- Definir metricas de sucesso
- Comunicar resultados para stakeholders
- Tomar decisoes baseadas em dados

3. PROCESSO DE CIENCIA DE DADOS (CRISP-DM)

3.1. ENTENDIMENTO DO NEGOCIO
- Definir objetivos e requisitos do projeto
- Formular perguntas de negocio
- Definir metricas de sucesso

3.2. ENTENDIMENTO DOS DADOS
- Coletar dados de diversas fontes
- Explorar dados iniciais
- Descrever dados (estatisticas basicas)
- Verificar qualidade dos dados

3.3. PREPARACAO DOS DADOS
- Limpeza: tratar valores ausentes e inconsistentes
- Transformacao: normalizar, padronizar
- Engenharia de features: criar novas variaveis
- Selecao de features: escolher as mais importantes

3.4. MODELAGEM
- Escolher algoritmos apropriados
- Dividir dados em treino e teste
- Treinar modelos
- Avaliar desempenho

3.5. AVALIACAO
- Validar resultados com stakeholders
- Interpretar metricas
- Otimizar hiperparametros

3.6. DEPLOY
- Implementar modelo em producao
- Monitorar desempenho
- Atualizar modelo periodicamente

4. PRINCIPAIS ALGORITMOS DE MACHINE LEARNING

4.1. SUPERVISIONADO (com rotulos)
- Regressao Linear: prever valores continuos
- Regressao Logistica: classificacao binaria
- Arvores de Decisao: regras de decisao
- Random Forest: combinacao de arvores
- XGBoost: gradiente boosting
- SVM: maquinas de vetor suporte
- Redes Neurais: deep learning

4.2. NAO SUPERVISIONADO (sem rotulos)
- K-Means: agrupamento (clustering)
- PCA: reducao de dimensionalidade
- DBSCAN: agrupamento baseado em densidade
- Redes Neurais Autoencoder: compressao de dados

4.3. APRENDIZADO POR REFORCO
- Q-Learning: aprendizado por tentativa e erro
- Deep Q-Networks (DQN): combinacao com redes neurais

6. METRICAS DE AVALIACAO

6.1. CLASSIFICACAO
- Acurracia: (VP+VN)/(VP+VN+FP+FN)
- Precisao: VP/(VP+FP)
- Recall: VP/(VP+FN)
- F1-Score: media harmonica entre precisao e recall
- ROC-AUC: area sob a curva ROC

6.2. REGRESSAO
- MAE: erro absoluto medio
- MSE: erro quadratico medio
- RMSE: raiz do erro quadratico medio
- R²: coeficiente de determinacao

6.3. CLUSTERING
- Inercia: soma das distancias ao centro
- Silhouette Score: coesao e separacao

11. CONCEITOS FUNDAMENTAIS

11.1. OVERFITTING E UNDERFITTING
- Overfitting: modelo decora dados de treino (erro baixo em treino, alto em teste)
- Underfitting: modelo nao aprende padroes (erro alto em treino e teste)

11.2. BIAS E VARIANCE
- Bias: erro por suposicoes simplificadas
- Variance: erro por sensibilidade a variacao dos dados
- Trade-off: balancear bias e variance

11.3. VALIDACAO CRUZADA
- K-Fold: dividir dados em K partes, treinar K vezes
- Leave-One-Out: deixar um dado de fora em cada iteracao
